## Постановка задачи
Определить основные данные и реализовать интерфейсы игровых сущностей.
Определённые на текущий момент сущности:
1. Предмет расходник
2. Игрок
3. Оружие
4. Снаряд
5. Противник
## Учесть при реализации
Возможные данные для описания:
### Расходник
Подбирается когда игрок подходит близко к предмету
Имеет у себя поле с целочисленным значением, которое восстанавливает определённый параметр у игрока
### Игрок
Основная игровая сущность
Должен иметь у себя поля, такие как:
1. Здоровье
2. Пулл оружий
3. Максимальное количество боезапаса в оружии
4. Метр до запуска супер-способности
### Оружие
Основная боевая единица для игрока
Должно иметь у себя поля:
1. Количество урона
2. Количество оставшегося боезапаса
3. Снаряд
И метод - *Особый навык*
### Снаряд
Необходимая сущность для визуального отображения 
Должно иметь у себя обязательное поле - время жизни
### Противник
Основная игровая сущность
Должен иметь у себя поля, такие как:
1. Здоровье
2. Количество наносимого игроку урона
А также, "мозг" - некий алгоритм, для преследования игрока, нанесения ему урона и выполнения определённых действий (например как у демона дашнуться на игрока)
