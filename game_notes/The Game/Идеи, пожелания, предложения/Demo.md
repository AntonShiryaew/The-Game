## Рабочий прототип
Рабочий прототип может быть без текстур, без моделей
Главное - архитектура и геймплей
## Архитектурный (нижний) уровень
1. Сетевой протокол, правила передачи и приёма пакетов
2. Чтение .json файлов (если необходимо)
3. Передвижение игрока, динамика в движении
4. Генерация арены
5. Правила стрельбы
6. Описание классов сущностей
## Интерфейсный (верхний) уровень
1. *Шрифт*
2. Спрайты
3. 3D модели
4. Игровой интерфейс
5. Кнопки, слайдеры
