## 1. Общая информация
- **Жанр:** кооперативный ретро-шутер от первого лица (в духе Doom, Heretic, Quake).
- **Сеттинг:** тёмное фэнтези, средневековье, магия на границе с техникой (Warhammer, Witchfire).
- **Атмосфера:** мрачная, динамичная, мясная. Без сюжета — только чистый экшен.
- **Платформа:** ПК (Windows/Linux).
- **Движок:** Godot 4.x + C#.
- **Режим:** кооператив на 2 игроков (Host and Play).

## 2. Ключевые референсы
- Heretic, Hexen, Witchfire, Doom (стиль, оружие, враги)
- Quake (динамика, лабиринты)
- DUSK, Amid Evil, Boltgun (современные ретро-шутеры)
- Ultrakill, Turbo Overkill (скорость, отзывчивость)

## 3. Игрок и вид
- Вид от первого лица.
- Оружие по центру экрана (как в классических Doom/Heretic).
- Внизу экрана — шкала здоровья.
- Прицел — перекрестие (по умолчанию).
- Модель другого игрока — не проработана (позже).

## 4. Оружие (6 видов)
У каждого оружия есть **базовая атака** и **спелл**, активируемый при заполнении **шкалы килов** (одинаковая для всего оружия). Скорость передвижения зависит от выбранного оружия.

| Оружие           | Тип                              | Базовая атака                | Спелл (по заполнению шкалы)                        |
|------------------|----------------------------------|------------------------------|----------------------------------------------------|
| Арбалет          | Дальний бой                      | Обычные болты                | Превращается в пулемёт (скорострельность)         |
| Посох            | Дальний бой                      | Луч                          | Волна огня                                         |
| Меч              | Ближний бой                      | Удар, есть шкала блока       | Волна в направлении удара                         |
| Молот            | Ближний бой (медленный, тяжёлый) | Сокрушительный удар, есть шкала блока | Удар по земле — линия урона на дистанции |
| Колба            | Средняя дистанция, яд            | Бросок одной колбы           | Запуск 4 колб с разной дальностью                 |
| Книга заклинаний | Дальний бой                      | Прямой магический снаряд     | Создание щита, о который разбиваются враги        |

- **Шкала блока** есть только у милишников (меч, молот). Восстанавливается со временем. Можно блокировать атаки (детали позже).
- Патронов нет — оружие стреляет бесконечно (позже, возможно, появятся ресурсы).

## 5. Здоровье и ресурсы
- Здоровье восстанавливается **красными колбами**, висящими в воздухе (как в Quake).
- Колбы появляются на арене.
- Брони нет (позже).
- Шкала килов заполняется убийствами врагов, не сбрасывается при переключении оружия.

## 6. Враги
- **Скелет** — ближний бой, подходит и бьёт.
- **Дух** — летающий, стреляет снарядами.
- **Демон** — средняя дистанция, атакует рывком (царапает).
- Все враги ищут оптимальный путь до игрока (навигация по лабиринту).

## 7. Уровни и генерация
- **Процедурная генерация**: берётся большая прямоугольная карта, на ней генерируется определённый процент стен — получается лабиринт.
- Враги спавнятся бесконечно (арена-режим).
- Уровни пока только для теста — бесконечная арена с нарастающей сложностью (больше врагов).

## 8. Смерть и воскрешение
- После смерти на месте игрока появляется **крестик**.
- Другой игрок может зажать кнопку, чтобы воскресить (время воскрешения не определено, но можно подобрать).
- Воскрешающий игрок получает урон от мобов.
- **Дружественный огонь** есть: игрок может случайно нанести урон напарнику.
- Если умирают оба — поражение (рестарт арены или волны).

## 9. Мультиплеер
- **Host and Play**: один игрок создаёт игру (хост), второй подключается по IP (в том числе через localhost для теста).
- Хост управляет игровым миром (враги, коллизии, спавн), клиент отправляет свои действия.
- Синхронизация позиций и действий через `MultiplayerSynchronizer` и RPC.
- Тестирование: локально на одном ПК (два окна).

## 10. Технические детали
- **Графика:** спрайты в 3D-мире, оружие от первого лица — спрайтовое (нарисованное), враги и предметы — тоже спрайты.
- **Ассеты:** пока планируется использовать готовые спрайты (OpenGameArt, Realm667 и др.) для прототипа, в дальнейшем возможна замена на свои.
- **Звук и музыка:** не определены, использовать бесплатные наборы на первое время.
- **Инструменты:** Godot 4.x, C#, Visual Studio Code или Rider, Git.

## 11. MVP (минимальный жизнеспособный продукт)
**Цель:** запустить кооператив на двоих на одной арене с бесконечным спавном врагов и тремя видами оружия.

**Задачи:**
1. Одиночный прототип: игрок, движение, стрельба из 2-3 оружий, враги (скелет, дух, демон), здоровье, колбы.
2. Сетевая часть: подключение двух игроков, синхронизация позиций, стрельба через RPC.
3. Система смерти и воскрешения (крестик).
4. Бесконечный спавнер врагов с нарастающей сложностью.
5. Процедурная генерация простого лабиринта.
