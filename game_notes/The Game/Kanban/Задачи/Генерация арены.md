## Постановка задачи
Для игры "The Game" должен быть реализован алгоритм генерации арены.
Сама арена должна представлять из себя 3D пространство со следующими элементами:
1. Пол
2. Стены
3. Склоны / подъёмы

>[!attention] Внимание!
Каждый элемент арены должен иметь текстуру
## Учесть при реализации
Код должен быть расширяемые, в случае необходимости добавления новых объектов на арену, таких как:
1. Прыжковые платформы
2. Трамплины
